commit `df42ac5b6bddfe531268335e2dcb496559cd488b`. MHC class I, `peptide_hla` scope.

## Convert

From this directory, use an actual Neoantimon2 v0.3.0 Export Bundle:

```sh
python3 converter.py --input input-X.tsv --output standard.tsv --bundle bundle
```

The checked-in `bundle/` is a minimal synthetic parser fixture, not a complete
core project export. Real use requires `neo_export_bundle(completed_project)`.
`input-X.tsv` is the Registry-mandated fixture name; its actual delimiter is
'\t'. Native required columns and exact metric mappings are in
[PROVENANCE.json](PROVENANCE.json). Output is the standard 18-column TSV;
`expected.tsv` is the independently authored expected result. Output must be new;
input, existing files and bundle contents are never overwritten. On any malformed
record conversion fails before producing output. Duplicate logical predictions,
including identical duplicates, are errors.

## Interpretation and limits

CNN multiple mode only, 9/10-mers, human A/B/C. Not GAN output. No HLA rescue, allele truncation or calibrated-probability claim; users must confirm exact supported upstream allele.

Scores are preserved verbatim without rescaling. Raw scores use unitless units
unless explicitly nM; genuine percentiles use percent/lower-is-better and their
own documented semantic channel. Provider/model IDs distinguish each method;
run_id is a deterministic input SHA256 identity because native outputs do not
supply a run identifier. source_row retains input hash, physical row and column
(and upstream sample label where present). Unknown schemas/unsupported banners
are rejected; versionless CSV/TSV cannot prove which executable produced it.
Users must retain the pinned predictor/model provenance. Model_version is empty because the native file does not identify a weights
release. Actual weights were not inspected or executed. Two-field HLA spellings are normalized reversibly; no
fuzzy mapping, allele guessing, higher-resolution truncation or best-allele
broadcast is performed. Blank/NA handling is explicit in provenance; other
missing/nonfinite values fail. Never request somatic grading implicitly.
